# Wireframes y referencias

Copia aquí wireframes, capturas, exports de Figma/PDF y referencias visuales que el agente pueda leer. Conserva nombres claros y evita reemplazar referencias originales.

En el prompt maestro indica rutas concretas, por ejemplo:

- `references/wireframes/01-dashboard.png`
- `references/wireframes/02-learning-path.png`
- `references/wireframes/03-lesson.png`

Para archivos fuera del repositorio, usa rutas absolutas accesibles desde la sesión de Antigravity. Si hay un PDF, solicita inspección por página; no asumas que la extracción de texto basta para interpretar el diseño.
