# Project discovery

1. Inspect the brief and every provided wireframe/reference; record inaccessible inputs.
2. Inventory screens, controls, navigation, states, roles and responsive variants.
3. Extract confirmed facts, assumptions, contradictions and unanswered questions.
4. Define problem, users, outcomes, MVP and explicit out-of-scope items.
5. Convert requirements into measurable acceptance criteria.
6. Record sources and evidence paths. Do not invent missing behavior.
7. Update context, requirements and journey docs; send the lead a concise decision summary.
